SegmentedControl은 같은 내용을 다른 밀도로 보는 전환이다. 패키지 상품의 "간략 일정 / 상세 일정"과 같은 자리.

- 트랙은 `surface-sunken`, 선택 항목은 `surface` 면에 `shadow-sm`. 선택 항목만 `ink`와 600 굵기, 나머지는 `ink-muted`.
- 높이 `control-sm`(36px). 터치 영역은 부모가 44px로 보장한다. 항목은 2~3개, 라벨은 4자 이내가 좋다.
- 선택은 `aria-pressed`로 표현하고, 선택 전환은 220ms `cubic-bezier(.2,.8,.2,1)`로 배경이 미끄러진다. 상태는 즉시 바뀌고 모션이 뒤따른다.
- 상세 모드 선택은 날짜를 바꿔도 유지된다(기존 앱 동작). 소비자는 현재 모드와 변경 콜백을 넘긴다.
- 탭(화면 이동)에는 쓰지 않는다. 화면 이동은 BottomNav나 상단 탭이다.
