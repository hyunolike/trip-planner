Toast는 방금 한 행동의 결과를 한 줄로 확인시킨다. 화면 하단, BottomNav 위 `space-4` 떨어진 자리에 하나만 보인다.

- 면 `ink`, 텍스트 `canvas`(반전). 아이콘은 `success`(완료) 또는 `danger`(실패). `radius-md`, `shadow-md`.
- 문구는 결과를 과거형으로: `링크를 복사했어요`, `2일차에 일정을 추가했어요`. 실패는 원인과 행동: `저장하지 못했어요. 연결을 확인해 주세요`.
- 행동 버튼은 하나(`실행 취소`, `다시 시도`). 완료 토스트는 3초 뒤 사라지고, 실패 토스트는 사용자가 닫을 때까지 남는다(`role="alert"`).
- 새 토스트가 오면 이전 것을 즉시 교체한다. 쌓지 않는다.
- 소비자가 넘기는 것: 메시지, 톤(success·error), 선택적 행동 라벨과 콜백.
