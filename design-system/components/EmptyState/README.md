EmptyState는 비어 있는 섹션이 다음 행동을 말하게 한다. 일러스트 한 장, 제목 한 줄, 설명 한 문장, 버튼 하나(또는 없음)의 순서로 세로 중앙 정렬한다.

- 일러스트는 `assets/Illustrations`에서 화면에 맞는 것을 고른다: 일정 `empty-itinerary`, 준비물 `empty-checklist`, 검색 `empty-search`, 공유 `empty-share`, 오프라인 `offline`. 최대 200px, `alt=""`(장식).
- 제목 `title-md`, 설명 `body` `ink-muted` 32자 이내. 설명은 비어 있는 이유가 아니라 채우면 생기는 일을 말한다: `첫 일정을 추가하면 시간순으로 정리되고 지도에 경로가 그려져요.`
- 버튼은 하나. 주요 행동이면 `--primary`, 선택적 행동(기본 목록 불러오기)이면 `--secondary`. 오프라인처럼 사용자가 할 일이 없으면 버튼을 두지 않는다.
- 위아래 여백 `space-10`. 섹션 전체가 비었을 때만 쓰고, 목록 일부가 비면 쓰지 않는다.
- 소비자가 넘기는 것: 일러스트 종류, 제목, 설명, 선택적 버튼 라벨과 콜백.
