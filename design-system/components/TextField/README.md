TextField는 스톱·장소·메모 편집의 기본 입력이다. 라벨은 항상 위에 보이고, 플레이스홀더는 라벨을 대신하지 않는다.

- 구조: `tn-field` > `tn-field__label` + `tn-field__input` + 선택적 `tn-field__help`. 필수 표시는 라벨 끝 `*`(`danger` 색).
- 높이 `control-md`(44px), 테두리 `line`, 포커스 시 `brand` 테두리와 `surface-brand` 3px 링. 오류는 `tn-field--error`로 테두리와 도움말이 `danger`로 바뀐다.
- 시각·날짜·코드 입력에는 `tn-mono`를 더해 고정폭으로 조판한다.
- 텍스트 영역은 같은 클래스에 `textarea`를 쓰고 최소 88px, 세로 리사이즈만 허용.
- 도움말은 한 문장. 오류 도움말은 원인과 형식을 함께 적는다: `24시간 형식으로 입력해 주세요. 예: 09:50`.
- 소비자가 넘기는 것: `id`(라벨 연결 필수), 값, 플레이스홀더, 도움말, 오류 여부. 자동 저장은 입력 800ms 후 필드 단위로 일어나며 TopBar의 편집 바가 상태를 보여준다.
