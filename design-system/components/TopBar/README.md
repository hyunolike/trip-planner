TopBar는 여행 노트의 머리다. 제목 하나와 아이콘 버튼 둘(공유·편집)까지만 둔다. 편집 모드에서는 아래에 32px 편집 바가 붙어 저장 상태를 말한다.

- 높이 `nav-height`(56px), 면 `surface`, 아래 `line`. 모바일에서는 왼쪽 뒤로 가기, 데스크톱에서는 로고가 그 자리.
- 제목은 `title-sm`(16px 600), 한 줄 말줄임.
- 편집 바 `tn-editbar`: `surface-brand` 위 `brand` 텍스트, 상태 점 8px. 문구는 `편집 중 · 저장됨`, `편집 중 · 저장 중`. 실패는 `tn-editbar--error`로 `danger-soft` 위 `다시 시도` 버튼과 함께.
- 저장 상태는 필드 단위 자동 저장의 결과를 합쳐서 보여준다. 한 필드라도 실패하면 실패 상태.
- 공유 버튼은 공유 시트를, 편집 버튼은 같은 화면의 편집 모드를 연다. 보기 전용 권한이면 편집 버튼 대신 `보기 전용` Badge를 둔다.
- 소비자가 넘기는 것: 제목, 권한(owner·editor·viewer), 편집 여부, 저장 상태(saved·saving·error).
