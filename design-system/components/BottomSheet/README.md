BottomSheet는 모바일에서 짧은 입력과 선택(일정 추가, 공유, 날짜 선택)을 받는다. 데스크톱(≥1024px)에서는 같은 내용이 오른쪽 사이드 패널(폭 400px)로 열린다.

- 면 `surface`, 위 모서리 `radius-lg`, `shadow-sheet`. 뒤는 `overlay`로 딤. 손잡이 36×4px `line-strong`.
- 머리: 제목 `title-md`. 본문 간격 `space-4`. 바닥에 `tn-btn--primary tn-btn--lg` 하나. 취소는 스크림 탭, 아래로 끌기, 뒤로 가기.
- 열림 220ms 아래에서 위로, 닫힘 140ms. 열릴 때 첫 입력에 포커스, 바깥은 `inert`. 포커스 트랩과 ESC 닫기는 필수.
- 키보드가 올라오면 시트가 같이 올라가고 본문은 스크롤된다. 시트 높이는 화면의 90%를 넘지 않는다.
- 소비자가 넘기는 것: 제목, 본문(폼), 주요 버튼 라벨과 콜백, 열림 상태. 입력 중 닫으면 초안을 버릴지 묻지 않고 유지한다(다시 열면 복원).
