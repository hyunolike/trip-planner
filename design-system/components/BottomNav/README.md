BottomNav는 여행 노트 안의 다섯 섹션(일정·맛집·쇼핑·링크·준비)을 오간다. 600px 미만에서만 쓰고, 그 위에서는 같은 항목이 상단 탭이 된다.

- 높이 `nav-height`(56px) + `env(safe-area-inset-bottom)`. 면 `surface`, 위에 `line`.
- 항목은 24px 아이콘과 11px 라벨. 선택은 `aria-current="page"`와 `brand` 색. 알약 배경은 쓰지 않는다.
- 아이콘은 `assets/Icons`의 `nav-*` 다섯 개를 인라인 SVG로 넣어 색이 토큰을 따르게 한다.
- 섹션 이동은 URL 해시(`#itinerary`, `#food`…)와 동기화한다. 뒤로 가기가 섹션 사이에서 동작해야 한다.
- 편집 모드, 전체화면 지도, 바텀시트가 열려 있을 때는 숨긴다.
- 소비자가 넘기는 것: 현재 섹션, 변경 콜백. 항목 수는 다섯으로 고정.
