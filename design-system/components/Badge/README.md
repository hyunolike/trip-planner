Badge는 정보의 근거 수준과 상태를 한 단어로 붙인다. 22px 높이, `label` 스타일.

- 기본(회색): `가족 계획`처럼 사용자가 정한 계획. `surface-sunken` 위 `ink-muted`.
- `--confirmed`: 예약 확정, 저장됨, 완료. `success-soft` 위 `success`. 체크 아이콘과 함께.
- `--brand`: 공식 안내·상품 안내·공개 샘플. `surface-brand` 위 `brand`.
- `--check`: 방문 전 확인, 변경 가능. `warning-soft` 위 `warning`.
- `--danger`: 승선 불가, 만료. `danger-soft` 위 `danger`. 되돌릴 수 없는 조건에만.
- `--pill`은 화면 상단 권한 표시(보기 전용)와 메타 정보용 둥근 꼴.
- 색만으로 뜻을 전하지 않는다. 텍스트가 항상 있고, confirmed는 아이콘도 함께 쓴다.
- 소비자가 넘기는 것: 텍스트, 톤, 선택적 아이콘. 한 행에 배지는 둘까지.
