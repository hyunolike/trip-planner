Button은 한 화면에서 다음 행동 하나를 가리킨다. `tn-btn`에 변형 클래스를 하나만 더한다.

- `tn-btn--primary`: 화면당 하나. `brand` 채움, `on-brand` 텍스트. 시트 하단과 여행 만들기 단계의 진행 버튼.
- `tn-btn--secondary`: 같은 줄의 보조 행동(링크 복사, 취소). `surface` 면에 `line-strong` 테두리.
- `tn-btn--ghost`: 텍스트만, `brand` 색. 목록 끝의 "더 보기", 인라인 행동.
- `tn-btn--danger`: 삭제와 되돌릴 수 없는 행동. 텍스트만 `danger`. 채움 버튼으로 만들지 않는다.
- 크기: 기본 `control-md`(44px). `--sm`은 36px(칩 옆 보조), `--lg`는 52px 전체 폭(시트·단계 하단). `--icon`은 정사각 44px이며 `aria-label`이 필요하다.
- 라벨은 동사로 끝나는 2~6자: `일정 추가`, `링크 복사`. 아이콘은 라벨 왼쪽 20px 하나만.
- 소비자가 넘기는 것: `type`, 라벨, 선택적 아이콘 SVG, `disabled`. 로딩 중에는 `disabled`와 라벨 교체(`저장 중`)로 표현하고 스피너는 넣지 않는다.
- 하지 말 것: 한 줄에 primary 둘, 명조 서체, 그라디언트, 44px 미만 터치 영역.
