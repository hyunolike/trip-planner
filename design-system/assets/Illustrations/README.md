# 여행노트 스팟 일러스트

| 파일 | 크기 | 사용하는 화면 |
| --- | --- | --- |
| empty-itinerary.svg | 240×160 | 일정이 없는 여행 일정표 |
| empty-checklist.svg | 240×160 | 준비물 목록이 비어 있는 여행 준비 |
| empty-search.svg | 240×160 | 장소 검색 결과 없음 |
| empty-share.svg | 240×160 | 공유받은 여행 없음, 첫 공유 안내 |
| offline.svg | 240×160 | 오프라인과 네트워크 연결 실패 |
| hero-route.svg | 640×360 | 여행 생성과 온보딩 히어로 |

모바일의 최대 표시 너비는 히어로를 포함해 200px이다. 높이는 원본 비율에 따라 자동으로 맞춘다. 데스크톱에서는 빈 상태 240px, 히어로 640px까지 표시한다. 배경은 투명하며 밝은 서비스 화면에 배치한다.

파일마다 #2456D6, #E7EDFB, #8A93A2, #EEF1F5 중 2~4색을 사용한다. 빈 일정에서는 핀에만 #2456D6을 사용했다. 면은 외곽선 없이 구성하며 점선 경로와 지도 격자에만 선을 쓴다. 그림자, 그라디언트, 얼굴, 사람은 없다. 따뜻한 강조색과 초록은 이번 세트에서는 사용하지 않았다. 이후 추가할 때 #A3570A는 작은 강조에만, #177A44는 식물에만 사용한다.

컨택트 시트는 빈 일정, 준비물, 검색, 공유, 오프라인, 히어로 순서다. 히어로는 가로 비율을 유지해 축소했다.
