# 여행노트 A안 3차

접힌 노트와 출발점, 네 개의 경로 점, 도착 핀을 유지한 기하 로고다. 모든 글자는 폰트 없이 채움 경로로 그렸다. 1차 `A/`, `build_logos.py`와 그 밖의 1차 산출물, 2차 `final/`은 수정하지 않는다. 확정된 워드마크 두 파일은 2차 파일을 바이트 그대로 복사한다.

색은 brand `#2456D6`, ink `#171B22`, white `#FFFFFF`만 사용한다. 콘택트 시트의 밝은 배경은 `#EEF1F5`다. SVG에는 텍스트, stroke, style, 외부 참조, 그라디언트와 필터가 없다. 흰 요소를 명시적으로 채운 기본 심볼과 달리 mono 파일은 바깥과 안쪽 둥근 사각형의 차를 evenodd로 채운 5단위 외곽선에 경로, 핀, 접힘을 같은 색으로 채운다. 접힌 모서리의 대각선도 안쪽으로 5단위 오프셋한다. 핀의 구멍은 노트 또는 배경색을 드러낸다.

OG의 `(80, 520)`은 워드마크의 왼쪽 아래 기준점이다. 실제 배치 상자는 x=80, y=464, 높이=56이다. 오른쪽 흰 모티프의 352×352 기준 상자는 brand 면의 중심 `(960, 315)`에 맞췄다. SVG 텍스트 요소와 별도 문구는 없다.

## 보호 여백과 최소 크기

로고 바깥 네 방향에 **심볼 높이의 25%** 이상을 비운다. 기본 가로 조합은 37단위, 독립 64 심볼은 16단위다. 워드마크만 쓸 때도 높이의 25%를 기준으로 삼는다. 보호 여백은 타이트한 SVG viewBox 바깥에 확보한다. on-brand 파일에는 37단위 내부 패딩이 이미 포함되어 있으며, 배경 바깥 보호 여백은 별도다.

최소 크기는 **가로 조합 높이 24px, 심볼 32px, 워드마크 높이 18px**다. 이 크기는 로고 외곽 높이 기준이다. 배경을 포함한 on-brand는 실제 조합 부분이 24px 이상이 되도록 전체 높이를 36px 이상으로 쓴다. 작은 글자와 경로의 세부 모양이 중요한 곳에서는 더 크게 사용한다. favicon은 전용 단순화 파일을 쓴다.

가로세로 비율 변경, 글자 사이 간격 변경, 지정색 변경, 회전, 그림자, 그라디언트, 입체 효과를 금지한다. 워드마크를 폰트로 대체하거나 경로 점을 추가하지 않는다. 흰 파일은 충분히 어두운 배경에서 사용한다.

## 브리프와 다른 점 및 수치 충돌

**공통 획은 18 대신 14**, 공통 격자는 **100×100 대신 100×148**이다. 148 높이는 1차 A안과 2차 브리프의 `18/148` 기준을 이어받았다. **트의 세 빈틈은 8 대신 약 30.67**로 통일했다. 심볼과 글자의 간격 27은 채택된 A안의 값을 유지했으므로, 조정된 획 14의 1.5배인 21과는 다르다.

모든 수치를 동시에 만족시킬 수는 없다. 획 18과 빈틈 8로 트의 가로획 네 개를 쌓으면 높이는 `18×4+8×3=96`이다. 반면 행의 ㅎ은 구멍 14를 확보할 때 링 지름이 최소 `18×2+14=50`이므로, 상단만 `18+8+18+8+50=102`가 필요하다. 높이 96의 상단 66%는 63.36으로 이 조건을 수용하지 못한다. 폭도 `ㅎ 링 50 + 자소 간격 8 + 줄기 18 + 줄기 사이 25.2 + 줄기 18 = 119.2` 이상이라 요청 폭 상한 104를 넘는다.

따라서 네 글자의 폭, 높이, 밑선과 간격을 통일하고 행의 구멍과 자소 간격을 확보하는 쪽으로 조정했다. 이번 심볼에서 핀 머리 중심은 기준 `(42,28)` 부근에서 `(42,32)`로 4단위 내려 접힘과 4.17단위 간격을 확보했다. favicon의 점 2개는 출발점 `(16,46)`, 지름 8과 경로 점 `(16,25)`, 지름 7로 구성했다. 핀 구멍 지름은 7이다.

## 검증

로컬에서 다음 명령으로 재생성하고 검사한다. Python의 Pillow, NumPy, Shapely와 `xmllint`, `rsvg-convert`가 필요하다. 네트워크, 외부 폰트, 이미지 생성 모델은 사용하지 않는다.

```bash
python3 final2/build_final.py
```

납품 SVG 14개와 검증용 글자 SVG 4개 전부 XML 검사와 librsvg 렌더를 통과했다. 명시적 hex 채움, 금지 요소와 속성 부재, 소수 둘째 자리, 파일당 12KB 이하를 함께 검사한다. 가장 큰 납품 SVG는 4,763바이트다. 2차 `final/` 파일의 실행 전후 SHA-256 일치와 워드마크 두 파일의 바이트 일치도 확인한다.

글자 PNG는 **8px/단위**로 렌더하고 알파 128을 경계로 삼는다. 연결 성분은 8방향 기준이며, 최소 간격은 서로 다른 성분 외곽 픽셀 중심 거리에서 1픽셀을 뺀 보수적인 값이다. 같은 자소 안에서 이어지는 획의 접합은 정상 연결로 센다. 구멍은 별도로 측정했다.

| 글자 | 연결 성분 | 성분 사이 최소 간격 | 구멍 지름 | 실제 너비 |
|---|---:|---:|---|---:|
| 여 | 2 | 15.38 | 32 | 100 |
| 행 | 6 | 8.00 | 14, 14 | 100 |
| 노 | 2 | 8.00 | — | 100 |
| 트 | 2 | 30.62 | — | 100 |

행은 위 가로획 두 개, ㅎ 링, ㅏ, 오른쪽 ㅣ, 받침 ㅇ의 6성분이다. 1차의 5성분과 달리 ㅐ의 두 줄기를 짧은 가로획으로 붙이지 않았다. 세부 측정값은 `validation/report.json`에 보존한다. 글자 확대, 밝은 배경과 어두운 배경, 실제 축소 크기, 앱 아이콘과 OG 렌더도 육안 확인했다.

32px 기본 심볼을 실제 픽셀로 검사한 결과 흰 연결 성분은 출발점 1개, 경로 점 4개, 핀 1개, 접힘 1개의 **7개**다. 경로 점 네 개는 서로 분리되며, 점 사이 최소 픽셀 간격은 **2.61px**다. 흰색 피복률 약 50%를 경계로 삼고 8방향 연결을 센다. 간격은 성분 외곽 픽셀 중심 거리에서 1px을 뺀 값이다. 16px favicon도 점 2개, 핀, 접힘의 **4개 성분**을 유지한다. 실제 크기 렌더와 최근접 확대본은 `validation/`과 콘택트 시트 마지막 줄에 보존한다.

단색 심볼 두 파일도 32px에서 각각 7개 연결 성분을 유지한다. 외곽선과 접힘은 한 성분이며 출발점, 경로 점 네 개, 핀은 외곽선에서 분리된다.
